# D-020: API versioning under /v1 with one-season backward compatibility

**Date:** 2026-10-29  
**Status:** Accepted

## Context

Old app versions must keep working for at least one season (User Flows doc).

## Decision

All public routes under `/v1`. Changes are additive only. The previous season's `openapi.json` is kept in `packages/openapi/previous/` and `oasdiff` fails CI on a breaking change.

## Advantages

- Old apps keep working
- Breaking changes are caught mechanically

## Compromises

- Deprecated fields linger for a season
- Removals need a dated TODO entry

## Revisit when

At each season boundary.
