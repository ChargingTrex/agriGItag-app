# D-013: Riverpod and go_router in the Flutter app

**Date:** 2026-10-29  
**Status:** Accepted

## Context

About 45 screens with mostly simple state; Drift streams drive live UI.

## Decision

flutter_riverpod with riverpod_annotation; one Notifier per screen flow; go_router with role-based redirect and an `/assist/:farmerId` scope.

## Advantages

- Least boilerplate among mainstream options
- Providers are overridable in tests
- Drift streams map directly to providers

## Compromises

- Codegen dependency
- Needs discipline to avoid provider sprawl

## Revisit when

If the team already knows Bloc well and prefers it.
