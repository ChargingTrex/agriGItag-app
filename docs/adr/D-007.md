# D-007: Static public page built by a worker job, served from object storage behind a CDN

**Date:** 2026-10-29  
**Status:** Accepted

## Context

QR scans happen in shops on weak networks and must survive backend outages.

## Decision

On publish and on every later change, a Celery job renders `index.html`, `data.json` and `qr.png` into the versioned `public-pages` bucket. Previous versions are retained.

## Advantages

- Sub-2-second loads
- Pages survive backend outages
- Every version of a page remains retrievable

## Compromises

- Rebuild on every change
- Old versions accumulate (by design)

## Revisit when

If pages need per-visitor personalisation.
