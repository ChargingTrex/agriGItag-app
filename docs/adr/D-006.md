# D-006: Rules run on the phone as a preview and on the server as the authority, sharing one JSON rule bundle

**Date:** 2026-10-29  
**Status:** Accepted

## Context

Farmers need instant feedback offline; the FPO needs a single source of truth.

## Decision

The phone downloads Standards Profile limits, GI outline and yield thresholds as a versioned bundle and runs previews. The server re-runs every rule after sync and at every approval gate. A contract test feeds the same fixtures to the Dart and Python implementations.

## Advantages

- Instant GI tick and yield warning with no signal
- Server result is final

## Compromises

- Two interpreters (Dart and Python) of one JSON
- Contract tests must be kept in step

## Revisit when

If the preview rules are ever compiled once (e.g. WASM) and shared.
