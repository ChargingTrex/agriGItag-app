# D-010: Ponytail ruleset plus the Documentation Standard

**Date:** 2026-10-29  
**Status:** Accepted

## Context

The user wants the least code that works, and code that human developers can maintain with the reasoning preserved.

## Decision

Ponytail (`CLAUDE.md` §4) governs code volume. The Documentation Standard (`CLAUDE.md` §5) governs headers, function docs, DECISION comments and error codes. Reviewers enforce both.

## Advantages

- Less code to maintain
- Reasoning survives the people who wrote it

## Compromises

- Agents hold two rules in tension; reviewers arbitrate

## Revisit when

Never; tune the standard instead.
