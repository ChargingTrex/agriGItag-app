# D-008: MinIO locally as the S3 stand-in with versioning and object lock

**Date:** 2026-10-29  
**Status:** Accepted

## Context

Production uses S3 with Object Lock; local development needs the same API.

## Decision

docker-compose runs MinIO; `minio-init.sh` creates `evidence` (versioning + object lock, governance mode, short retention in dev), `public-pages` and `id-docs` buckets.

## Advantages

- Same API locally and in production
- Immutability is testable on a laptop

## Compromises

- Object-lock semantics differ slightly from AWS
- Production still needs an infra review

## Revisit when

If local tests never exercise object lock, a lighter stand-in may do.
