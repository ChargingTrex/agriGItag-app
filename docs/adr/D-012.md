# D-012: Schema-first: one initial migration before module agents start

**Date:** 2026-10-29  
**Status:** Accepted

## Context

Parallel agents editing Alembic independently would conflict on migration heads.

## Decision

WP-B01 writes every table and `0001_initial`. Module work packages add small follow-up migrations reviewed centrally.

## Advantages

- No Alembic head conflicts
- Reviewers see the whole model at once

## Compromises

- Some columns may go unused in the pilot
- Schema changes need a small central review

## Revisit when

Once the team is small enough to coordinate migrations informally.
