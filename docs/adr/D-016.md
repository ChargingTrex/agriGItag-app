# D-016: Tamil and English voice and icons bundled in the app; everything else as downloadable bundles

**Date:** 2026-10-29  
**Status:** Accepted

## Context

First run must work offline for the pilot FPOs; the app must stay small.

## Decision

Recorded Opus clips for ta and en ship in the APK; other languages, FPO product pictures, GI outlines and standards arrive as versioned bundles after sign-in.

## Advantages

- Offline first run
- Small download
- FPO content updates without an app release

## Compromises

- First sync must pull bundles (officer does it on Wi-Fi during onboarding step 9)
- More cache and version logic

## Revisit when

If a third language becomes the default for a pilot FPO.
