# D-019: GI region derived from open administrative boundaries with recorded provenance

**Date:** 2026-10-29  
**Status:** Accepted

## Context

The GI Registry publishes boundaries only as prose and map drawings (Application 883, Certificate 693, GI Journal 200).

## Decision

Region v0 = Virudhunagar district outline; v1 = dissolved union of the taluks named in the journal, built by `infra/scripts/gi_boundary/build_virudhunagar.py` from the Datameet / Census 2011 sub-district layer (open licence). GADM 4.1 only as a cross-check because its licence forbids commercial use. Every version stores `source_ref`, `licence`, `confidence: district_derived`, `taluks[]`.

## Advantages

- Reproducible and legally usable
- Close to the legal definition
- Replaceable by an official file without schema change

## Compromises

- Taluk boundaries changed after 2011
- The taluk list must be confirmed from the journal (TODO)
- Still an approximation, so the tolerance buffer and near-edge review stay on

## Revisit when

When an official or surveyed boundary file is obtained.
