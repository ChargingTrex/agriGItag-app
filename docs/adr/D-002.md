# D-002: Flutter + Material 3 for Android and iOS, 100 MB hard size ceiling, 30 MB download target

**Date:** 2026-10-29  
**Status:** Accepted

## Context

The User Flows doc targets Android Go phones and a 30 MB app; the architecture doc left iOS open. The user asked for both platforms, Material 3, and raised the budget to 100 MB.

## Decision

One Flutter codebase, Material 3 theme with large-target tokens. Android 8+ and iOS 13+. Hard ceiling 100 MB on the universal APK; device-specific App Bundle download target 30 MB via per-ABI splits and on-demand voice packs.

## Advantages

- One codebase for both platforms
- Material 3 gives accessible large-target theming out of the box
- 100 MB leaves room for bundled Tamil audio and product pictures

## Compromises

- iOS adds signing and CI lanes
- A large APK installs slowly on weak 4G, so the 30 MB download target still matters
- iOS background sync is best-effort

## Revisit when

If the pilot FPOs are Android-only after one season, iOS lanes can be paused.
