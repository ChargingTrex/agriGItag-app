# D-003: Monorepo with clients generated from one OpenAPI contract

**Date:** 2026-10-29  
**Status:** Accepted

## Context

Three clients (mobile, portal, public page builder) consume one API.

## Decision

Single repository. `packages/openapi/openapi.json` is exported from the API and used to generate the Dart (`openapi-generator`, dart-dio) and TypeScript (`openapi-typescript`) clients. Generated code is never edited by hand.

## Advantages

- One contract, no drift between clients and server
- Field descriptions written once in Pydantic appear in Swagger, Dart and TS

## Compromises

- A codegen step in CI
- Generator fidelity limits on unions must be respected (no anyOf, no recursive models)

## Revisit when

If a client needs hand-written models for performance or ergonomics.
