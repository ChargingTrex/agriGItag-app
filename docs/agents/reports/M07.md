## What was done

**One Notifier per flow.** `EventLogNotifier` (`lib/features/event_log/event_log_controller.dart`) holds the draft.
It loads the lot's field rules, plot, history and standards once, in `start()`. It offers four previews:
- the out-of-order question
- the yield preview
- packing readiness
- the payload

`save()` writes everything in one Drift transaction:
- `EntriesDao.save(entry, media)`
- the tasks it completes
- the packing lot status
- the drying reminder

Then it calls the `afterSaveProvider` hook. `undo()` reverses all of that. Screens compose the M05 kit only.

**Payload (D-014).** Field names follow `apps/api/agritrace/modules/events/payloads/farm.py` exactly, and quantities are
`{value, unit}`:

| Event | Payload |
|---|---|
| land_preparation | `cultivated_area` from the plot, `last_ploughed_on` (ISO day) |
| nursery | `seed_variety` |
| sowing | `seed_variety` copied from the nursery entry |
| input_application | `input_id`, `quantity` = bags × pack size in the input's unit (Decimal math; `{bags, "bag"}` when the master has no pack size) |
| harvest | `quantity` kg, `bags` |
| drying | `phase` |
| packing | `quantity` kg, `bags` |
| problem | `problem_type` |

Disabled fields and nulls are dropped.

The entry carries:
- the three clocks (device time at save, GPS time of the fix; the server adds its own)
- lat/lng/accuracy and `locationStatus`
- `enteredByUserId` from the Session row
- `assistMode`
- `instanceNo` (standing versions of this type + 1)
- `undoDeadline` = deviceTime + 24 h

Media rows carry the sha256, width/height and thumbPath from `CompressedPhoto`; a voice note is a `voice` row.
`ownerUserId` is left as `TODO(M02)`: the column does not exist on main.

**Field config (D-017).** `FieldRules` reads `FieldConfigDao.get('event_<type>')`, as a list or `{fields: [...]}`.
Before the first pull every field shows and none is required.

**Router.** The farmer role gained `/log`. The routes added are:
- `/home/{saved,sell,money,farm}` (Sell, Money and My farm are placeholders until M08/M09)
- `/log`
- `/log/:eventType`, which redirects to `/log` when the type is unknown
- `/log/:eventType/confirm`, which redirects back when there is no photo
- `errorBuilder`

`EventFlowScreen` is keyed by event, so a new flow never reuses an old one's state.

**Placeholder screen.** The speaker shortcut is replaced: the screen now has a "Coming soon." prompt bar and speakers on
its buttons. The settings placeholder holds the language switch, because the farmer home has no room for it.

**Other files.**
- 75 new ARB keys in ta and en, each with `@description`. Prompt id = key.
- 8 placeholder clips per language (copies of the M05 tone), listed in `prompts.json`.
- 9 placeholder webp pictures, 1.7–2.4 KB each, labelled "PLACEHOLDER".
- `path_provider` is now declared directly. It was already in the tree through drift_flutter, so no new package; I
  added a LIBRARIES row.
- `integration_test` (Flutter SDK, dev only) added, with a LIBRARIES row. `flutter test integration_test/` refuses to
  run without it.

**Undo.** Undo is on the Saved screen. History and the entry-detail Undo are M08's.
