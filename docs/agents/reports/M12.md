## What was done

- **Local reminders** (`lib/features/notifications/reminders.dart`, flutter_local_notifications 22.3.3):
  - `scheduleReminders` cancels every pending reminder, then schedules one per open task in the Tasks table
    whose time is still ahead: at the due time (a due day at midnight rings at 07:00), inexact (no exact-alarm
    permission). Title "Time to log: Harvest" / "பதிவு செய்யும் நேரம்: அறுவடை" in the app locale, body the
    farmer's field ("Field 2", same numbering as Money/Sell), payload `/log/<event>?lot=<lot id>` only.
    No name, phone, farmer id or ID document can enter the text (built from the event and field number).
  - `startReminders` (bootstrap): plugin init with the tap handler (warm start), launch details (cold start),
    and a serialized reschedule on every change of the open tasks (`openTasksProvider` over the new
    `TasksDao.watchOpen()`), the session (role, language) and the Settings switch. Only the farmer role gets
    reminders. This covers app start, the drying reminder M07 writes, completion (task done → gone), undo, and
    any pull that writes Tasks (Drift stream; the pull writes none today, see Skipped).
  - `openReminder`: `go('/home')` then `push(payload)`, so the event opens on M08's `/log/<event>?lot=` route
    (D-043: lot preselected, no field picker) with home underneath; any non-`/log/` payload is ignored.
  - `askReminderPermission`: the first time a reminder is scheduled, a dialog with the spoken rationale
    ("AgriTrace can remind you when it is time to log the next step, like harvest. Allow reminders?") and
    farmer-size Yes / No; Yes calls the Android 13+ / iOS permission request. The answer is kept in SyncState
    (`reminders_permission_asked`), so it is asked once.
  - `remindersOnProvider`: Settings switch state in SyncState (`reminders` = `off` when off; default on).
- **Settings**: one `SwitchListTile` "Reminders" with the speaker button, after "Photos on Wi-Fi only".
- **Push seam** (`push.dart`): `PushProvider` interface, `ConsolePushProvider` (no token), `registerPush` gated by
  `features.push_notifications` of the `fields` bundle (absent → off). No Firebase dependency; `shortcut:` comments
  + TODO name the human Firebase/APNs step and the missing device-token endpoint.
- **Platform setup**: Android manifest `RECEIVE_BOOT_COMPLETED` + the plugin's two receivers; Gradle core library
  desugaring (`desugar_jdk_libs:2.1.4`); iOS AppDelegate `UNUserNotificationCenter.current().delegate`.
- **Strings**: `reminderTitle`, `remindersToggle`, `remindersRationale` (ta + en). No voice clips (text only).
- **Docs/tracking**: D-046 (ADR + DECISIONS row + `DECISION D-046` comment), LIBRARIES rows (plugin with its
  Android/iOS setup lines, its federated packages, timezone), CHANGELOG line, TODO (follow-ups, debt, manual step).
