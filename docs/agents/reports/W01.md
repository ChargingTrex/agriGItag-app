# W01 report: public QR page renderer (`agritrace_page`)

Worker: Opus · Branch: worktree branch for W01 (not merged) · Date: 2026-10-29

## Done

- **Package** `apps/public-page` (`agritrace-page`, Python >=3.12,<3.13, `.python-version` 3.12, uv,
  hatchling build so B10 can depend on it by path). Runtime deps: jinja2 and pydantic only. Dev deps:
  html5lib, pytest, ruff, interrogate. No database or network code anywhere.
- **`schema.py`**: `PublicBatchRecord` and nested models (Quantity, Reading, Photo, Place, GeoPoint,
  InputUsed, Event, Grade, Processor, Lot, Footer). Every field has `description=`.
  - `extra="forbid"`: the schema is the public allow-list (`DECISION D-017`).
  - A before-validator walks the raw record and refuses private key names, phone numbers, Aadhaar-like
    numbers, survey/patta/chitta, polygons, coordinate arrays, precise coordinate text, and
    `temp_uploads` or `/tmp/` paths. Nested model instances are walked too.
    `hide_input_in_errors=True` keeps the rejected value out of the error text.
  - Photo URLs must match an `evidence/` path. Pins are rounded to 3 dp in the schema
    (`DECISION D-017`). Timelines are sorted by (date, instance_no).
  - Cross-checks: shares add up to 100 ± 0.1, best-before is after pack date, a range does not end
    before it starts, and `lab_name` is allowed only when `lab_certified`.
  - Computed fields: `lot_count`, `event_count` per lot, `farming_event_count`,
    `processing_event_count` and `map_link`.
- **`render.py`**: `render(record, *, lang_order=("ta","en")) -> RenderResult(html, data_json)`.
  - Jinja2 with autoescape and StrictUndefined; a missing label fails the build.
  - Bilingual labels, Tamil first, from `i18n/ta.json` and `i18n/en.json`.
  - Formats: "14 Feb 2026" dates, Indian grouping, last-updated time in UTC.
  - Address segments are de-duplicated. Opted-out farmers show as "Farmer N" / "விவசாயி N".
  - `measure()` and `BUDGETS` are shared by the CLI and the tests.
- **Templates**: `batch.html.j2` (single template with `qty()` and `timeline()` macros), `page.css`
  and `page.js`, all inlined.
  - The GI indicator uses colour plus shape plus text (✓ verified / ▲ not verified). The Lab-certified
    badge (★) appears only when the grade is lab-certified.
  - Each photo is a `<picture>` with a WebP thumbnail, a JPEG fallback, width/height and lazy loading.
    The JS (577 B) enlarges a thumbnail to the medium WebP in place. Without JS the link opens the
    medium image.
  - Per-lot timelines use native `<details>`, so they expand with JS off (`DECISION D-007`).
  - A placeholder comment marks where W03 adds the print CSS and OG tags.
- **`cli.py`** / `__main__.py`: `python -m agritrace_page build <record.json> <out_dir>` and
  `python -m agritrace_page check <out_dir>`. `check` exits 1 when a budget is breached.
- **Fixture** `fixtures/batch_sample.json`: reference batch FGP8T4033HM7 with the PRD §12.2 data
  problems fixed:
  - Lots: 100 + 200 + 20 kg = 320 kg, shares 31.25 / 62.5 / 6.25 %. Each lot reconciles:
    harvested ≥ packed ≥ sold ≥ used.
  - Organic tags match the organic and bio inputs. IPM is claimed only on the lot that has a neem
    bio-pesticide event.
  - Every quantity has a unit and instances are in date order. The processor address has no repeated
    segment.
  - Grade "Standard" against AGMARK Dry Chillies & Capsicums, Schedule IV, with moisture 10.4 %
    from an instrument.
  - GI verified. Location methods are mixed: two live GPS pins (one with a review note) and one
    walked boundary.
  - FSSAI and GI user numbers are `DEMO-...` placeholders. Photos are under
    `https://evidence.example/evidence/...`.
  - Farmer names are fictional ("Kannan Example", "Selvi Example"). Lot 2 has opted out and shows as
    "Farmer 2". There are no phone numbers.
- **Docs**: README (what it does, how B10 calls it, budgets, adding a label), 8 LIBRARIES rows,
  CHANGELOG line.
