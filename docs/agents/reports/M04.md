## What was done

All in `apps/mobile/lib/core/capture/`. Each piece sits behind a small seam a test can fake. There are no UI screens; M07 builds the camera screen.

| File | What it gives M07 |
|---|---|
| `camera_capture.dart` | `CameraCapture.open()` opens the back camera directly. It returns `false` when access is refused, so M07 can show its own sheet and no error code reaches the farmer. `controller` feeds `CameraPreview`. `take({fix})` returns a `CapturedPhoto` (file, `Clocks`, fix). The camera list, the controller factory and the clock can all be injected. The preset is `ResolutionPreset.veryHigh`, recorded as `DECISION D-002` (see Deviations). Audio is off and output is JPEG. |
| `photo_compressor.dart` | `compress(file, {capturedAt, fix, maxBytes})` runs in `compute`. It reads the JPEG size first and decodes at a 1/2 to 1/8 DCT scale where that still gives at least 1600 px (a 12 MP frame decodes at about 3 MP). Then it resizes to a 1600 px long edge with no upscaling, runs the JPEG ladder `80, 75 … 40` until the file is ≤ 350 KB, splices in the rewritten EXIF, and writes `<src>_1600.jpg` plus a 200 px q70 thumbnail `<src>_thumb.jpg`. It returns bytes, width, height, SHA-256 (crypto), thumbPath, the quality used and the `PhotoQuality` verdict. Carries `DECISION D-011`. |
| `exif_rewriter.dart` | `buildTiff(sourceExif, {capturedAt, fix})` and `splice(jpeg, tiff)`. The output keeps only Orientation (= 1, because the pixels are already upright), DateTimeOriginal, OffsetTimeOriginal and SubSecTimeOriginal (from the source, or from `capturedAt` when the source has none), plus a GPS IFD. The GPS IFD comes from `fix` when given (version, lat/lon DMS, altitude, UTC time and date, HPositioningError = accuracy in m); otherwise the source GPS tags are kept. Everything else is dropped by construction. I wrote a small spec-correct TIFF writer because package:image's `ExifData.write` leaves out the 4-byte next-IFD pointer after sub-IFDs (TIFF 6.0 §2). Reading still uses package:image. |
| `photo_quality_check.dart` | `check(Image) → ok / tooDark / tooBlurry`. It computes mean luminance and the variance of the 4-neighbour Laplacian over a grey copy with a 256 px long edge. `measure()` exposes both numbers for calibration. |
| `gps_fix.dart` | `LocationFix` (lat, lng, accuracyM, gpsTime, altitudeM?). `GpsFix.fixes()` is a stream for the ring. `waitForAccuracy(target: 20 m, timeout: 60 s)` returns `GpsResult(best, lowAccuracy)` and `locationStatus` (`ok`, `low_accuracy` or `none`, matching `Entries.locationStatus`). The default source is geolocator: it asks for permission once, and when permission is refused or location is off the stream is empty, which gives `none` straight away. Provider errors end the wait. |
| `clocks.dart` | `Clocks(deviceTime, gpsTime)` and `Clocks.stamp({fix, now})`. The server adds `serverReceivedAt` as the third clock. |
| `voice_note_recorder.dart` | `start(dir, name) → VoiceStart.recording / micDenied`. `stop()` and `result` return a `VoiceNote(file, duration, sha256)`. A 30 s timer stops recording by itself, and calling stop twice is safe. Opus/OGG mono 24 kbps where the platform encodes it (Android 10+); AAC-LC/M4A mono 32 kbps on iOS and Android 8–9. 16 kHz. |
| `capture_constants.dart` | The single file of thresholds: 1600 px, 350 KB, the ladder, thumbnail size and quality, 256 px analysis size, luminance 40, Laplacian variance 100, 20 m, 60 s, 30 s, bit rates. |

## Decisions and deviations to review

1. **Capture preset is `veryHigh` (1080p), not `medium`.** The brief said "`ResolutionPreset.medium`-class". On the camera plugin, `medium` is 480p (720 × 480). That is below the 1600 px long edge PLAN §13 B1 asks for, so every stored photo would be ~720 px. `high` (720p, 1280 px) is also below 1600. `veryHigh` is the smallest preset above 1600 px, and it still avoids the 12 MP `max` buffers that drive PSS. This is recorded as `DECISION D-002` at `_defaultController`. If the Orchestrator wants `medium` anyway, change that one line and accept photos below 1600 px.
2. **Orientation is baked into the pixels and written as 1** instead of copying the camera's tag. package:image's decoder applies orientation and drops the tag anyway. Upright pixels also keep the thumbnail, the server's Pillow WebP variants (B06) and the portal correct without any EXIF-aware viewer. The tag is still present (= 1).
3. **Own TIFF writer** (about 60 lines in `exif_rewriter.dart`), because package:image 4.12.0 writes sub-IFDs without the next-IFD pointer. Android ExifInterface reads that slot after every IFD and would take value bytes as an offset.
4. **Two voice formats.** Opus/OGG needs Android 10+. iOS AVAudioRecorder writes Opus only into CAF. So iOS and Android 8–9 record AAC-LC/M4A, and the server (B06) must accept `audio/ogg` and `audio/mp4`.
5. **The ladder floor is q40.** If a photo is still over 350 KB at q40, it is saved anyway (D-011 COMPROMISE). Evidence is never dropped because of size. There is no retry loop.
6. The compressor does **not delete the camera original**. M07 deletes it after storing the Media row ("originals are not kept"), because the compressor deleting its input would be a surprising side effect.

## Risks

- **Pure-Dart decode speed on Android Go.** On the host it takes 0.8–1.6 s for 12 MP. A slow phone could take several seconds. With the 1080p preset the real input is about 2 MP, so this should be well under 2 s, but it is unmeasured. M07 should show progress while the isolate runs.
- **What `gpsTime` really is.** It is geolocator's `Position.timestamp`. On fused or network fixes Android derives it from system time, not from GNSS. The server's clock-skew check should treat `gpsTime` as advisory unless the accuracy is good.
- The ladder only stepped down in the test with a lowered `maxBytes`. The smooth fixture fits at q80 (95 KB). Real 1600 px field photos are expected at 200–400 KB at q80, so the ladder will run in the field.
- One full-suite run reported "+55 -1" and the next three were green. The failing test was not captured. Watch for a flake, possibly CPU contention between the isolate-heavy compressor tests and goldens.
