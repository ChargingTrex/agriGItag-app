## What was done

All widgets are in `apps/mobile/lib/core/widgets/`. Each one composes Material 3 parts and reads its sizes from
`FarmerTokens`. Each speaker has a `Semantics` label from the ARB files. No widget uses colour alone.

| Widget | What it is |
|---|---|
| `PictureCardGrid<T>` + `PictureChoice<T>` | Two columns built with `Wrap` (not `GridView`, so cards grow with text scale instead of overflowing). Each card is `Card.outlined` + `InkWell`: picture, label across the full card width, optional speaker under the label. **Selected** = 3 dp primary border + `check_circle` badge + primaryContainer fill. The card's semantics node carries `selected`, `button` and the tap. |
| `BigStepper` | Controlled int. 64 dp `IconButton.filled` − / +, disabled at `min` / `max`. Value in `en_IN` grouping (1,20,000) with the unit under it, in a live region. Long-press repeats every 150 ms and stops at the bound. |
| `NumberPad` | Controlled raw string. 3 × 4 grid of 64 dp `FilledButton.tonal` keys: 0–9, backspace, optional point. Read-out uses Indian grouping and the unit. Limits: one point, `maxDigits` (7), a lone `0` is replaced. No TextField anywhere. |
| `StatusBadge` + `FarmerStatus` | done / todo / attention as the M00 glyph (tick / open circle / triangle) plus a word in the glyph colour. One merged semantics node. |
| `VoicePromptBar` | Speaker + sentence. Plays `promptId` after the first frame when `voiceAutoplayProvider` is true; a tap replays it. If the clip is missing or fails, the speaker becomes `volume_off` labelled "No voice", the text stays, and `VoicePlayer.missingClips` is incremented. No TTS. |
| `CallFieldOfficerButton` | `FarmerButton(Icons.call, "Call officer")` → `launchUrl(tel:<n>)`. The number comes from `fieldOfficerPhoneProvider`, so the button can be dropped into any screen. Disabled while the number is null. |
| `ConfirmScaffold` | App bar (title + optional `CloudSyncIndicator`), `VoicePromptBar` with the summary, the preview filling the free height, a 64 dp full-width tick (`onConfirm` null disables it, for D-017 required fields), Retake, and `CallFieldOfficerButton`. |
| `CloudSyncIndicator` | Watches `pendingSendCountProvider` (`StreamProvider<int>`): grey `cloud_upload` + count while entries wait, green done tick at 0. Shows nothing before the first value, so it never claims "all sent" early. |
| `AssistBar` | Full-width tertiaryContainer strip, `support_agent` icon + "Logging for: <name>" (ta/en). |
| `GpsRing` | Determinate `CircularProgressIndicator`, so there is no custom painter at all. Empty with no fix, linear from 100 m to 20 m, full + green + tick icon at ≤ 20 m. Accuracy shown as "± N m". The sentence is a `VoicePromptBar` keyed by prompt (`gpsHold` → `gpsFound`, so it speaks again when the ring turns green). "Save anyway" `FarmerButton` appears after a 60 s `Timer` while the fix is still weak. |
| `ErrorSheet` | One picture, one `VoicePromptBar` sentence, one prominent 64 dp `FarmerButton`. Callers show it with `showModalBottomSheet`. |

`FarmerButton` is unchanged.

**Voice** (`lib/core/voice/`):

- `prompt_catalog.dart` parses `assets/prompts.json` (`{"clips": {"ta": [ids], "en": [ids]}}`). It maps
  `assetFor(promptId, locale)` to `assets/audio/<lang>/<id>.ogg`, or to null when the clip is not bundled.
- `voice_player.dart`: `VoicePlayer.play(promptId, locale) → bool` plus the `missingClips` counter. Audio sits
  behind a one-function seam, `typedef ClipPlayer = Future<void> Function(String assetPath)`.
- `voicePlayerProvider` backs that seam with one just_audio `AudioPlayer` (`setAsset` + unawaited `play`) and
  disposes it with the provider.
- `voiceAutoplayProvider` and a `playPrompt(ref, context, id)` helper complete the module.
- Two placeholder clips per language, `callOfficer` and `gpsHold`: 0.4 s tones made with ffmpeg/libopus, mono,
  48 kHz, 24 kbps, 1.3–1.4 KB each. `prompts.json` says `"placeholder": true`.

**l10n.** I added 19 keys to both ARB files, each with an `@description`:
- status words;
- stepper, number-pad and voice labels;
- `callOfficer`, `confirmCorrect`, `retake`;
- the plural-free `cloudPending(count)`, `cloudAllSent` and `loggingFor(name)`;
- `gpsHold`, `gpsFound`, `gpsAccuracy(metres)`, `saveAnyway`, `photoNotClear`.

Every label a farmer sees is at most two words. `gen/` was regenerated.

**DECISION comments:**
- D-002 in `number_pad.dart` and `big_stepper.dart`: Material 3 buttons at the 64 dp token.
- D-016 in `voice_player.dart`: bundled Opus clips through just_audio, with the iOS Ogg caveat.
- D-016 in `pubspec.yaml`: the assets block.

No new decision numbers were needed.

    `MinimumTapTargetGuideline(56×56)` over every semantics tap target, `labeledTapTargetGuideline` and
    `textContrastGuideline`. An overflow at 1.5× would fail here too.
  - **Primary action size:** the ConfirmScaffold tick is 328×64 (full width); Retake and Call are 328 wide;
    the ErrorSheet action is 64 tall, 328 wide and the only button; NumberPad keys are 64; stepper buttons 64×64.

    `12000.5`; maxDigits and lone-0.
  - **BigStepper:** min/max with disabled buttons; long-press repeat (fake time) stops at max 5; Indian grouping.
  - **GpsRing:**
    - 15 m gives value 1.0, colour `StatusGlyph.done`, a tick and "Location found";
    - 35 m gives 0.8125 and is not green;
    - no fix: "Save anyway" is absent at 59 s, present at 60 s, full width, and the tap fires;
    - at 12 m there is no "Save anyway" after 60 s.
  - **CloudSyncIndicator:** with a `StreamController`, nothing shows before a value; 3 gives cloud + "3" + label;
    0 gives a green tick + "All sent".
  - **PictureCardGrid:** two per row, card width 156; the tap selects; tick and `isSelected` in semantics.
  - **CallFieldOfficerButton:** a mocked `plugins.flutter.io/url_launcher` channel receives `launch` with
    `tel:+919876543210`.
- **`voice_test.dart`:**
  - every manifest id has its `.ogg` file and is an ARB key in both languages (packaging guard);
  - `assetFor` paths and nulls;
  - per locale, a bundled clip autoplays the right path and replays on tap;
  - a missing clip plays nothing, sets `missingClips == 1`, shows the text, `volume_off` and "No voice";
  - autoplay off plays nothing.

## Risks

- **iOS cannot play `.ogg`.** AVPlayer, which just_audio uses on iOS, has no Ogg demuxer. The spec's Ogg/Opus
  clips are silent on iOS: the screens fall back to text and the misses are counted, but nothing crashes.
  An iOS pilot needs a second container (CAF-Opus or AAC); this is noted in the D-016 comment.
- **APK size.** just_audio brings ExoPlayer (Media3) into the Android build, roughly 1–2 MB. It was not measured
  because no release build was allowed. Re-check with `tool/size_check.sh` in M13.
- **Files outside my declared paths.** `flutter pub get` rewrote `ios/Flutter/{Debug,Release}.xcconfig` (CocoaPods
  include) and generated `ios/Podfile`, because the app now has plugins. These are standard Flutter-generated
  files that iOS builds need, so I kept them.
