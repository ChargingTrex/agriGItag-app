## What was done

- **apps/api package `agritrace`** (Python 3.12 pinned by `requires-python` and `.python-version`, locked with uv):
  - `main.py`: app factory, OpenAPI 3.1 metadata and one tag per module, Brotli middleware with gzip
    fallback, error-envelope handlers, `/v1` router (D-020), auto-mounting of `modules/*/router.py`
    (so parallel WPs never edit main.py), `GET /v1/healthz` running real `SELECT 1`, Redis `PING` and S3
    `HEAD evidence` checks concurrently, each with a 3 s timeout and its own `error: <reason>`. Returns 503
    when any check fails.
  - `core/`: `config` (pydantic-settings, all 12 variables, refuses dev JWT secret / OTP code when
    `ENV=prod`), `db` (async engine, sessionmaker, `get_session`, `Base` with a naming convention),
    `ids` (`uuid7`, `lot_code`, `batch_code`, `superlot_code`), `errors` (`AppError` with auto-registry
    that refuses duplicate codes; 11 codes, including the 9 required plus `method_not_allowed` and
    `internal_error`, which the envelope handlers need), `schemas` (Quantity, SignedQuantity, GeoPoint,
    ThreeClocks, ClientRef, Page[T], ErrorEnvelope), `task_names`, `storage` (presigned PUT bound to the
    SHA-256 via `ChecksumSHA256`, head, get_stream, put_public), `time` (`utcnow`, `clock_skew`), and
    `audit` (placeholder).
  - `worker/__init__.py`: Celery on `REDIS_URL`, autodiscovers `agritrace.modules.*.tasks`,
    `worker_process_init` hook that drops the inherited engine (D-009).
  - 11 empty module packages with headers and `__all__ = []`.
  - `export_openapi.py`, `alembic.ini`, `alembic/env.py` (async engine, `Base.metadata`, GeoAlchemy2
    alembic hooks, `search_path=public`), `alembic/script.py.mako`, `Dockerfile` (python:3.12-slim, uv,
    non-root uid 10001), `.dockerignore`, `.env.example`.
  - Tooling in `pyproject.toml`: ruff (pydocstyle google plus D417), mypy strict with the pydantic plugin,
    interrogate at 100 % (private, magic and nested functions included), and two import-linter
    contracts for D-004 (an independence contract between modules that ignores only `-> *.models` and
    `-> *.service`, and "core never imports modules").
- **Tests:** `tests/conftest.py` starts session-scoped testcontainers for PostGIS, Redis and MinIO,
  creates the buckets, injects env vars, provides an httpx AsyncClient over the app and turns on eager
  Celery. Unit tests: ids, errors, schemas/time/config (19 tests). Integration tests (`integration`
  marker): healthz all ok, healthz independent failure, presigned PUT that checks the SHA-256.
- **infra:** `docker-compose.yml` (db, redis, minio, minio-init, mosquitto, api, worker; named volumes;
  every host port can be remapped through an env var), `scripts/minio-init.sh`,
  `scripts/gen-error-codes.py`, `README.md`.
- **Root `Makefile`** with up, down, logs, test, test-unit, lint, openapi, clients (placeholder), seed
  (placeholder), progress and error-codes.
- **Docs:** `docs/api/conventions.md`; `docs/api/error-codes.md` (generated); 25 rows in
  `docs/LIBRARIES.md`; one line in `CHANGELOG.md`.

## Round 2 (Orchestrator follow-up: LocalStack for D-008, Valkey for D-021)

### What changed

- **S3 stand-in is now LocalStack.** Compose service `s3` (`SERVICES=s3`, port 4566, host override
  `S3_PORT`, healthcheck on `/_localstack/health` requiring s3 available/running). A one-shot `s3-init`
  (`amazon/aws-cli`, gated on `s3` healthy) runs `infra/scripts/s3-init.sh`, renamed from
  `minio-init.sh`. It creates:
  - `evidence`: created with `--object-lock-enabled-for-bucket`, versioning on, default retention
    GOVERNANCE 1 day.
  - `public-pages`: versioning on, plus a bucket policy allowing anonymous `s3:GetObject`.
  - `id-docs`: private, with a public access block.
- **App env in compose:** `S3_ENDPOINT=http://s3:4566`, `S3_PUBLIC_ENDPOINT=http://localhost:${S3_PORT}`,
  `S3_REGION=ap-south-1`, credentials `test`/`test`. Path-style addressing was already on.
- **No MinIO volume any more:** the LocalStack community image keeps no data across restarts, so
  s3-init recreates the buckets on every start.
- **Two S3 endpoints:** `core/config.py` has new `S3_PUBLIC_ENDPOINT` and `S3_REGION` settings.
  `core/storage.py` keeps one cached boto3 client per endpoint: `client()` talks to `S3_ENDPOINT`, and
  `presign_put` signs against `S3_PUBLIC_ENDPOINT`. Both are documented in `.env.example` and
  `infra/README.md`.
- **Valkey (D-021):** compose service `valkey` uses `valkey/valkey:8-alpine` with a `valkey-cli ping`
  healthcheck, and conftest uses `RedisContainer("valkey/valkey:8-alpine")`. Both image lines carry
  `DECISION D-021` comments with ADV/COMPROMISE. `REDIS_URL`, redis-py and Celery's redis transport are
  unchanged. The README explains the switch. There is no LIBRARIES row, because Valkey is a service, not
  a library.
- **HEAD on healthz:** `/v1/healthz` now also answers HEAD. There is one route per method, so the
  OpenAPI operation ids stay unique (`healthz_v1_healthz_get` and `healthz_v1_healthz_head`). New
  `tests/unit/test_healthz_unit.py` stubs the probes and checks GET 200 with the body, HEAD 200, and a
  single failing probe giving 503 on both methods with only `redis` in error.
- **Tests:** `tests/conftest.py` now uses testcontainers `LocalStackContainer` (S3 only, ap-south-1)
  instead of MinIO; the rest of the fixture is unchanged.
- **Dependencies:** removed `shapely`, `pyyaml`, `python-multipart` and `respx` from pyproject and their
  LIBRARIES.md rows, and switched the testcontainers extras from `minio` to `localstack` (uv also dropped
  `minio`, `numpy` and argon2 from the lock). pyyaml stays installed only as a transitive dependency of
  `uvicorn[standard]`.
