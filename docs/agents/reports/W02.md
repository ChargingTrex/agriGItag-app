## Open question for the Orchestrator: which "Slow 3G" BM-03 means

- **What BM-03 says.** It asks for the Lighthouse "Slow 3G" preset with LCP ≤ 2 s. Lighthouse has no such
  preset. Its only 3G constant is `mobileRegular3G` (300 ms RTT, 700 kbit/s), which the CI config now uses.
- **Why not the DevTools "Slow 3G" values.** With them (400 ms RTT, 400 kbit/s) the simulated LCP has a
  floor of about 2.0 s on this machine for any page: a 1 KB page with one heading gets a 2006 ms median,
  and this page 2007 ms. The cost is 3 RTTs before the first byte, plus 4× CPU. So with those values the
  gate measures the profile, not the page, and it fails whatever the template does. I tried
  `content-visibility:auto` below the fold, and it did not move LCP (2013 ms), which confirms this.
- **What it would take to switch.** Change two numbers in `lighthouserc.3g.yml` (`rttMs: 400`,
  `throughputKbps: 400`) and either raise the LCP threshold or accept a red BM-03.
- **Decision needed.** The choice belongs in an ADR or a plan-summary amendment. I marked it at the point
  of use as `DECISION D-007` with ADV/COMPROMISE, because no ADR exists for the profile.

- **The Lighthouse numbers are close to the line on slow CPUs.**
  - The 3G median LCP is about 1.58 s, against a limit of 2.0 s.
  - Performance swung from 0.91 to 0.99 across runs on this 2018 laptop (one run had TBT 346 ms of local
    noise).
  - Median-of-3 absorbs single outliers, but a slower CI runner could fail sometimes.
  - W03 adds CSS (print, OG tags, map thumbnail), so re-check both profiles after W03.
- **The fixture photos are not loaded.**
  - The host `evidence.example` does not resolve, and every photo sits in a closed `<details>`.
  - So the 6.9 KB first view has no images. That matches the real first view, but tells nothing about
    tap-to-enlarge weight.
- **The new coordinate forms fail closed.** A few prose shapes now count as leaks:
  - a word containing lat/lon/lng followed by `:` or `=` and a number with 4 or more dp (`calculated: 12.3456`);
  - any 4+ dp number followed by a degree sign;
  - two decimals split by a space where one has 4 or more dp.

  None appear on the built page or in the 90 probes.
- **npm quirk.** npm 11 crashes when adding html-validate without `--legacy-peer-deps`; the README says so.
  html-validate is pinned to 11.4.0 because 11.17 needs Node ≥ 24.8 and this machine has 24.7.
