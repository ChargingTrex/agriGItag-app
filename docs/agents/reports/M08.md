## QR format for M11

```
{"lotId":"<server lot UUID>","farmerId":"<server farmer UUID>","packedKg":300.0,"sig":"<11 chars>"}
```
- compact JSON, keys in this order, packedKg in **kilograms** rounded to 0.1 kg (a JSON number);
- `sig` = base64url, no padding, of the first 8 bytes of SHA-256 over UTF-8 `lotId|farmerId|packedKg`, packedKg
  written with one decimal (`300.0`);
- decode with `SellQr.decode(text)` from `package:agritrace/features/sell/sell_qr.dart`; it returns null for
  non-JSON, a missing/mistyped key or a wrong `sig`;
- **D-035:** `sig` is a checksum, not an HMAC (no secret is shared between phones; M06 has only per-install tokens).
  M11 must look the lot up (pulled `Lots` or the API) and check that it belongs to `farmerId` and that `packedKg`
  matches. The QR carries no phone number, name or location (CLAUDE.md §6).
