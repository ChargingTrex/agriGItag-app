## Deviations from the brief (each deliberate)

- **psycopg → pg8000.** psycopg and psycopg-binary 3.3.6 declare `LGPL-3.0-only` (checked from the installed
  metadata). D-018 rejects copyleft, so DatabaseLibrary uses pg8000 (BSD-3-Clause). This is recorded as
  `# DECISION D-018` in `common.resource` and `libraries-check.py`, and in the ledger's "Alternative rejected" column.
  libraries-check therefore flags LGPL as well as GPL/AGPL; MPL-2.0 stays allowed as LIBRARIES.md says. If B00 adds
  psycopg to apps/api, the check will fail. B00 has to switch to asyncpg (Apache-2.0), or the Architect-Gate has to
  allow LGPL explicitly.
- **interrogate `--ignore-init-method=false` is not a valid flag.** `-i/--ignore-init-method` is an on/off switch
  that is off by default (checked with `interrogate --help`, v1.7.0). doc-coverage.py omits it, which gives the
  intended behaviour, and the code comment explains why.
- **`pytest` is added to `qa/robot/requirements.txt`**, so one venv runs both the Robot suites and qa/tests.
- **The DECISION-id check scans apps/, packages/, infra/ and qa/**, not only apps/. This matches the ADRs' "Linked
  code" grep and also checks the QA layer's own comments.
- **Suite placement for WPs without their own suite**: B04 → `api/rules.robot`, B11 → `api/publishing.robot`,
  B13 → `api/registry.robot`. The mapping is listed in qa/robot/README.md.
- **"off/edge/lte" in the Q00 title** maps to `off`, `profile edge` and `profile normal_4g`.
- **BM-01 in §8 says "4-core throttled"; the Go AVD has 2 cores** because the Q00 title says so, and 2 cores is
  the stricter setting. This is noted in the benchmarks README.
