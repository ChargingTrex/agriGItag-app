## What was done

1. **Project.** `flutter create --org in.agritrace --project-name agritrace --platforms android,ios --empty`.
   Android `minSdk = 26` (DECISION D-002 comment in `android/app/build.gradle.kts`); iOS deployment target 13.0
   (the template default); `CFBundleLocalizations` ta/en in `Info.plist`; launcher label "AgriTrace".
   `lib/` matches mobile-design.md §1: every `core/*` and `features/*` folder exists with a one-line `README.md`
   (the README alone keeps the folder in git, so no `.gitkeep`).
2. **Flavors.** `lib/main_{dev,staging,prod}.dart` each call `bootstrap(Flavor.x)`; `AppConfig.fromEnvironment`
   reads `--dart-define=API_BASE_URL`. dev defaults to `http://10.0.2.2:8000`; staging and prod throw `StateError`
   without it, so a release cannot silently call a developer machine. No flavor plugin. `appConfigProvider` is
   overridden in `bootstrap`. Crash hooks (`FlutterError.onError`, `PlatformDispatcher.onError`) go to one
   `_report` seam that only prints for now (`shortcut:` comment, vendor in M13).
3. **Theme.** `core/theme/app_theme.dart`: `useMaterial3`, `ColorScheme.fromSeed(Colors.green)`, no dynamic
   colour, `materialTapTargetSize: padded`, `fontFamilyFallback: ['NotoSansTamil']`, `FarmerTokens` extension.
   `farmer_tokens.dart`: minTarget 56, farmerTarget 64, gap 16, plus done/todo/attention glyphs.
   `status_glyphs.dart`: green tick 0xFF2E7D32 (4.9:1), orange open circle 0xFFB45309 (4.8:1), red triangle
   0xFFC62828 (5.4:1). Contrast was computed against the light green-seed surface (≈ #F7FBF1).
   `app.dart` clamps text scale with `MediaQuery.withClampedTextScaling(1.0, 1.5)`.
4. **FarmerButton** (`core/widgets/farmer_button.dart`). Full-width `FilledButton.icon` plus a square
   `IconButton.filledTonal` speaker slot. Height comes from the tokens: 56 dp, or 64 dp when `prominent`.
   The label is asserted to be at most two words. The speaker has `Semantics(label: playVoice)` inside
   `MergeSemantics`. Goldens: `test/goldens/farmer_button_{en,ta}_{56,64}.png`.
5. **Routing.** `core/router/session.dart` holds a Riverpod `SessionNotifier` (role + locale; the only app state).
   `core/router/app_router.dart` has one table, `allowedPrefixes`, and one pure function, `redirectFor`:
   signed out → /auth, farmer → /home, field_officer → /officer (+ `/assist/:farmerId`), qc → /qc. The router is
   refreshed by a `ValueNotifier` that follows the session role. `placeholder_screen.dart` shows the role name and
   a language-switch `FarmerButton`.
6. **l10n.** `l10n.yaml`: arb-dir `lib/core/l10n`, **template `app_ta.arb`**, output `lib/core/l10n/gen/`,
   `required-resource-attributes: true` (gen-l10n fails on a key without `@description`), preferred locale ta.
   Eight keys, each with an `@` description in both files. Font: `assets/fonts/NotoSansTamil-sub.ttf`, the Tamil
   block of Noto Sans Tamil Regular subset with fontTools (46.6 KB → 35 KB, all name/layout tables kept),
   with the OFL text next to it. It is shipped, not left as a TODO.
7. **API client.** Generated package `apps/mobile/packages/agritrace_api`. I picked this over
   `packages/client-dart/` because the Makefile `clients` target and mobile-design.md §1 already name it.
   `tool/gen_api.sh` runs `npx @openapitools/openapi-generator-cli@2.42.0` (generator jar 7.26.0 pinned in
   `openapitools.json`) with `dart-dio`. It deletes the output first, so operations removed from the spec
   disappear, then runs build_runner. The header says the output must never be edited by hand. Options are in
   `tool/openapi-generator-config.yaml` (the npm wrapper splits `--additional-properties` on spaces). The skip
   list is `tool/openapi-generator-ignore`, copied into the output first (`--ignore-file-override` was not
   honoured). `core/api/api_client.dart`: one dio with connect 10 s and receive/send 30 s, `X-Device-Id`
   header, `AuthInterceptor` (Bearer from a callback; refresh is a `shortcut:` for M06), and
   `healthz()` → generated `HealthApi.healthzV1HealthzGet`.
8. **Tooling.** `analysis_options.yaml`: flutter_lints + `public_member_api_docs`, strict casts and raw types,
   formatter width 120, generated code excluded. `tool/no_textfield_lint.sh` greps `TextField|TextFormField|
   CupertinoTextField` in `features/farmer_*` and the other farmer-only features (event_log, problem_report,
   sell, money, history, settings). Exit 1 means a hit; exit 2 means the check itself failed.
   `tool/size_check.sh` builds the release prod arm64 APK with `--split-debug-info`, fails above `MAX_MB`
   (default 100) and warns above `WARN_MB` (40). It measures the AAB with `bundletool get-size total` when
   bundletool is on PATH, and skips with exit 0 when there is no Android SDK.
9. **CI.** Q00's `ci.yml` is not on this branch, so the job is in **`apps/mobile/ci-job.yml`**, written to
   replace Q00's `mobile:` stub verbatim. Steps: subosito/flutter-action@v2 with `flutter-version: 3.38.4`,
   setup-java 17, pub get, no-TextField lint, `dart format --set-exit-if-changed`, `flutter analyze --fatal-infos`,

10. **Ledger.** 13 rows in `docs/LIBRARIES.md`. Q00's `infra/scripts/libraries-check.py` (run from a scratch

**Size detail (acceptance "arm64 APK < 15 MB").** The arm64 APK is 15,396,551 bytes. That is 14.68 MiB, so
the script passes (it counts 1 MB = 1,048,576 bytes), but it is 15.40 MB in SI units, which Flutter prints as
"15.4MB". Whether the gate passes therefore depends on the unit, and the Verifier should decide. What it
contains:

| Entry | Bytes | Stored as |
|---|---|---|
| lib/arm64-v8a/libflutter.so (engine) | 11,107,920 | uncompressed |
| lib/arm64-v8a/libapp.so (our Dart code) | 3,867,568 | uncompressed |
| classes.dex | 474,208 | deflated |
| fonts, NOTICES, shaders, other | < 200 KB | deflated |

- The native libraries are stored uncompressed. That is AGP's default for minSdk ≥ 23
  (`extractNativeLibs=false`): the phone maps them straight from the APK, so the installed size is smaller.
- The same APK gzipped is 7,064,709 bytes. That is roughly what Play or HTTP compression actually transfers.
- Measured alternatives:
  - Without `--split-debug-info`: 16,051,911 bytes.
  - With `--obfuscate` as well: 15,331,015 bytes (-65 KB). Not worth it, so not adopted.
  - With `packaging.jniLibs.useLegacyPackaging = true` (compressed .so): **7,100,015 bytes**. Not adopted, and
    reverted. It halves a side-loaded download, but the phone then extracts about 15 MB of libraries at install,
    which is worse for 2 GB Android Go phones. Play compresses downloads anyway.
- This needs a decision from the Orchestrator or Architect-Gate. Either the 15 MB skeleton gate is read in MiB
  or as a compressed download, or we flip to compressed libraries. That flip is one line in
  `android/app/build.gradle.kts` plus a D-002 note.

## Risks

- **Goldens are recorded on macOS but CI runs on Linux.** Glyph anti-aliasing differs between CoreText and
  FreeType. `test/flutter_test_config.dart` accepts up to 0.5 % differing pixels, but this is unproven on Linux.
  If the first CI run fails, regenerate the goldens on Linux (`flutter test --update-goldens` in the CI image)
  rather than raising the tolerance. The goldens load the real Tamil subset and MaterialIcons, from
  `$FLUTTER_ROOT/bin/cache/artifacts/material_fonts`. Latin text renders as test-font boxes, which is deliberate.
- **The `gen_api.sh` CI step needs network access** for npx and the generator jar download. CI also needs Java
  11+ (setup-java 17 is in the job).
- **The generated client depends on the latest `built_value` packages.** It pulls `one_of` and `built_collection`,
  and its pubspec says SDK `>=2.18`, which is harmless. A future generator bump can change the output; that is
  why the generator version is pinned.
