## Done

- **`features/exports/exportModel.ts`**
  - `csvCell` / `toCsv`: RFC 4180 quoting, CRLF line ends and a UTF-8 BOM. A `'` prefix goes on any cell that starts with `= + - @`, tab or CR (same rule as B11 `csv_cell`). No library.
  - `saveBlob`: P04's object-URL download code, moved here unchanged, including the 40 s revoke. `saveCsv` calls it.
  - `lotsCsvRows`: lot code, farmer name (P03 `useFarmerNames`), received + unit, packed share + unit (batch packed kg × share %, D-051), share + `%`.
  - `farmersCsvRows`: an allow-list of the dashboard's `FarmerRow` columns, in the dashboard's order. Each area column becomes value + `_unit`.
- **`features/exports/BatchExports.tsx`**: a "Labels and exports" section on the batch page with three `GatedButton`s:
  - Download labels: what is on the sheet, 8 per A4, and "print at 100 %, packs ÷ 8". Greyed for any role other than admin or QC, and before final packing.
  - Download audit CSV: B11 route, saved as `audit-<code>.csv` (the server's Content-Disposition name). Greyed for any role other than admin or viewer.
  - Download lots CSV: built in the browser, `batch-<code>-lots.csv`. Greyed while the lots load.
  - A server refusal is shown with P04's `GateReasons`.
- **`features/exports/ExportsPage.tsx`** (`/exports`; the sidebar entry "Labels & exports" changed from the `/labels` placeholder):
  - Farmers CSV `farmers-<fpoCode>-<YYYY-MM-DD>.csv`. It reads every page of `GET /v1/dashboard/fpo/{id}/farmers` with `?fields=` set to the dashboard's visible columns (P06's localStorage choice, else all columns), and the FPO code from `GET /v1/fpos/{id}`.
  - A link to Batches, because each batch's exports are on its own page.
- **`PublishSection.tsx`**: the duplicate "Download labels" button and its mutation are removed from the live-page block. The labels now live in one place, for packed and published batches. The P04 happy-path test still clicks "Download labels" and passes.
- **`BatchPage.tsx`**: renders `BatchExports` with the share lots it already reads and `farmerName`.
- **`AppRoutes.tsx`**, **`navigation.ts`**: add the `/exports` route and exclude P05 from the placeholder routes.
- **MSW** (`mocks/handlers.ts`): labels.pdf now returns binary bytes. New `audit-export.csv` handler: admin/viewer only, 404 for an unknown batch, CSV with `entered_by`, `assist_session_id`, `quantity` and `unit`.
- **Docs**: D-051 ADR and row; LIBRARIES.md "used in" rows for react-query, MUI, react-router, openapi-fetch and axe-core (no new library); CHANGELOG line; TODO (P04 → P05 closed; P05 → P06 merge line; P05 skipped line).

## Risks

- **Merge with P06:** P06 also edits `AppRoutes.tsx` (placeholder filter line, routes) and `navigation.ts`. Small textual conflicts are expected.
- **P06 storage key:** `visibleColumns` repeats P06's localStorage key `agritrace.dashboard.columns.<fpoId>` (`shortcut:` comment). If P06 renames the key before it merges, the farmers CSV falls back to all columns. That is still safe, because the allow-list holds.
