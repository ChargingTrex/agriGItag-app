### Commands to resume

```sh
# 0. Preconditions: host free disk ≥ 10 GiB (df -h /System/Volumes/Data), load < 20, stack healthy:
curl -s localhost:8001/v1/healthz            # want {"db":"ok","redis":"ok","s3":"ok"}
# 1. Boot the stand-in AVD (cold boot took 39 min at load 400+; expect ~3-5 min on a quiet host)
~/Library/Android/sdk/emulator/emulator -avd agritrace_go -no-window -no-audio -gpu swiftshader_indirect \
  -memory 2048 -cores 2 -no-snapshot-save -no-boot-anim &
adb wait-for-device; until [ "$(adb shell getprop sys.boot_completed | tr -d '\r')" = 1 ]; do sleep 5; done
adb shell cmd connectivity airplane-mode disable   # airplane mode was ON when the AVD was killed
adb shell cmd alarm set-time $(( $(date +%s) * 1000 ))   # auto time is off on the guest
# 2. Rebuild (main moved to ef9dac4: regenerated Dart client) and install
cd apps/mobile && export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
flutter build apk --profile -t lib/main_dev.dart --target-platform android-x64 \
  --dart-define=API_BASE_URL=http://10.0.2.2:8001
adb install -r -g build/app/outputs/flutter-apk/app-profile.apk
# 3. Cold start x3 (signed in), recording `uptime` and `adb shell cat /proc/loadavg` each time
adb shell am force-stop in.agritrace.agritrace; adb shell am start -W -S -n in.agritrace.agritrace/.MainActivity
# 4. Sign in farmer A +919000000092 (OTP 123456), then the network profiles
qa/scripts/network.sh profile normal_4g   # | weak_4g | edge | offline; airplane: adb shell cmd connectivity airplane-mode enable
# server-side check of a cell: rows created after T0
docker exec agritrace-db-1 psql -U agritrace -d agritrace -Atc \
  "select id,event_type,created_at from events where created_at>'<T0>'; select id,status,uploaded_at,verified_at from evidence_photos where created_at>'<T0>'"
# phone queue: adb exec-out run-as in.agritrace.agritrace cat app_flutter/agritrace.sqlite > /tmp/p.sqlite (plus -wal)
# 5. WorkManager: id from `adb shell dumpsys jobscheduler | grep -o 'systemjobscheduler:u0a[0-9]*/[0-9]*'`
adb shell cmd jobscheduler run -f -n androidx.work.systemjobscheduler in.agritrace.agritrace <id>
# 6. Clock jump (no root needed): adb shell cmd alarm set-time <epoch ms>
# 7. Integration test LAST (it uninstalls the app): adb logcat -c; flutter test integration_test/farmer_flows_test.dart -d emulator-5554
```

## Still needs the real API 27 (Android 8) image

These cannot be proven on the stand-in:
- minSdk 26/27 behaviour: install, the Material 3 and Flutter engine on Android 8, the camera plugin (camerax)
  on 8.x.
- Legacy permissions: runtime camera, location and microphone prompts without the Android 12+ approximate-location
  choice, no POST_NOTIFICATIONS (API 33+), and `RECEIVE_BOOT_COMPLETED` re-arming.
- WorkManager on Android 8: the JobScheduler path without namespaces (`-n` does not exist there), Doze and App
  Standby behaviour.
- Cleartext HTTP defaults, storage StatFs, and the low-RAM (`ro.config.low_ram`) Go behaviour.
- The API 27 SDK licence has to be accepted by a person first.
