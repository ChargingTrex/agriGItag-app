## Observations (no defect filed)

- The size line rests on the worker's build at round 1, and round 2 changed the manifest, the Gradle comments and Dart code. None of these changes adds a dependency or an asset, so a material size change is unlikely. The first Verifier with disk headroom (M02/M06) should still re-run `tool/size_check.sh`. bundletool should be installed then, so that the 30 MiB AAB target is measured.
- The generated client's `pubspec.lock` and `.dart_tool` are git-ignored, so a regeneration leaves the tree clean. `date.dart` has no generator header because the upstream template has none. It is never hand-edited, as the byte-identical regeneration shows.
