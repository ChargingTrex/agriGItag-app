## Outputs

`POST /v1/sync/push` (≤50 entries or 256 KB, per-entry transactions, `ON CONFLICT DO NOTHING` idempotency, kinds: event_version/quality_reading/plot/consent/flag_resolution, optional `metrics[]` stored in `sync_metrics`), presigned PUT per photo, `POST /v1/sync/photos/confirm`, `events.verify_photo` (sha256 + EXIF, enqueues rules) then `events.make_variants` (WebP thumbnail ~60 KB, medium ~150 KB into `evidence_photos.variants`), discriminated-union event payload schemas, undo ≤24 h, corrections

## Acceptance tests (Verifier executes each literally and records evidence)

- [ ] same `client_id` 2× → 1 row, 2nd `duplicate`
- [ ] foreign-owned id → `client_id_conflict`
- [ ] 51 entries → 422
- [ ] mixed batch: #1,#3 accepted, #2 rejected
- [ ] wrong checksum → `checksum_mismatch` + flag
- [ ] undo after 24 h → 409
- [ ] farmer correction → 403
- [ ] device clock +3 d → stored + `clock_skew` flag
