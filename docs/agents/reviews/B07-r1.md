### P2

**P2-1. Pull and the timeline hand out the original JPEG, with the phone's exact GPS in its EXIF**
(`events/evidence.py:243-264`, `signed_variants`)
- `signed_variants` presigns every `*_url`, including `jpeg_url`. That is the original evidence object, and
  M04 keeps its EXIF GPS on purpose.
- Before B07 the link was unsigned and did not work against the private bucket. Now it is a working
  1-hour link that anyone holding it can open: a forwarded timeline link, or one copied out of the
  portal's network tab.
- The WebP variants have no EXIF (B06 review row 17), and neither the phone nor the timeline needs the
  original to show a picture. The B06 privacy note (TODO line 141) is written for B10, but the same
  reasoning applies here.
- **Fix:** sign only the WebP keys and drop the original from these two views. For example, filter
  `k in ("thumb_url", "medium_url")` and leave `jpeg_url` out of the copy. Then update the
  `EventPhotoOut.variants` description, conventions.md "Photo URLs", and
  `test_signed_variants_presigns_urls_and_keeps_sizes`. A verifier or auditor flow that needs the original
  can presign it on purpose later.
- **If skipped:** an exact-location file travels through a link that has no auth check for an hour.

### P3

1. **Docs: Raises for pass-through errors.** `part_body`, `reference`, `pull`, `_changes`, `_pending_photos`
   and the builders do not list `sqlalchemy.exc.SQLAlchemyError`. `manifest` and `quality_service` do.
   `_gi_region` can pass through `NotFoundError` from `simplify_region` (practically unreachable). CLAUDE.md
   §5.2 asks for every pass-through exception. interrogate and D417 cannot see this.
2. **Spec drift (Orchestrator).** backend-design.md §3 still says `?since=<version>` and "newer than since".
   PLAN §13 C2 says "version > since". Both should be updated to the per-part `<part>:<version>` with
   "differs" that B07 implemented under TODO F1.
3. **Spec typo.** backend-design.md line 124 says `photos_pending`. The code, line 126 and OpenAPI say
   `photo_pending`. Fix the spec.
4. **Clock source of the settle bound** (`pull_service.py:353`). `now = utcnow()` is the API host clock,
   while `updated_at` is `func.now()` on the database. If the API clock is ahead of the database by close to
   30 s, the settle window shrinks without anyone noticing. Fix: compute the bound in SQL
   (`func.now() - PULL_SETTLE`), or read `select now()` once.
5. **Outline over 50 KB is served silently** (`_gi_region`). When 400 m still does not fit, log a warning
   with the byte size, so a bad import is noticed. One line.
6. **Farmer `plots` version is FPO-wide.** The `reference_versions` row is per FPO, so any plot change in
   the FPO makes every farmer's `?since=` return their unchanged `plots` body. It is small at pilot scale.
   Note it in TODO next to the "no cache" shortcut.
7. **Pulled photos go stale.** A photo's status or variants changing does not touch `events.updated_at`. A
   pulled event therefore keeps `variants: null` until the event itself changes, and its signed links die
   after 1 h. conventions.md says "re-read the timeline / pull". Since a pull will not re-send the event,
   M02 should take photos from the timeline. Add that to the M02 hand-off.
8. **Missing tests.**
   - No unit test pins the `farmer_json` key set. It is a privacy allow-list: one assert that it equals
     `{id, code, name, name_local, village_id, status, no_smartphone}` catches a future `phone` addition.
   - No integration case has an officer pulling or downloading `plots`/`farmer_profile` while a second FPO
     has rows. Integration test 5's neighbour is a farmer in the same FPO.
9. **Hand-off to B08.** Flag `details` now reaches the farmer's phone through pull. B08 rules (for example
   plot overlap or duplicates) must not put another farmer's name, code or plot in `details`.
10. **`sync_cursors.updated_at` is not bumped on pull** (`pull_service.py:364`). Push sets
    `"updated_at": now` on conflict and pull does not, so the sync-health views show the last push only.
    One key in `set_`.
11. **LIBRARIES "files" cells.** Add `apps/api/agritrace/modules/events/bundle_service.py` to the `shapely`
    and `geoalchemy2` rows (ledger hygiene; the check passes).
12. **Lean nits.** `presign_get(bucket=...)` has no caller that passes it. `signed_variants(expires=...)`
    has no caller that passes it. `presign_get`'s default of 900 s is never used. Drop the unused
    parameters, or leave them. About 4 lines.

Hand-off notes for M02/M06 (not findings against B07):
- Database-part versions are the same for a farmer and an officer of one FPO, while the bodies differ. A
  phone that switches user must wipe refdata on sign-out. Otherwise `since=plots:41` from the previous
